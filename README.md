# BEL247 Web

A Flutter web app for Belize Electricity Limited customers to view dashboard, bills/receipts, usage, and daily bill data per active account. Supports account switching and a mock data toggle.

- Active account controls all screens (Dashboard, Bills & Receipts, Usage, Daily Bill)
- Mock data lives in `assets/data/` (e.g., `mock_app_data.json`)

Quick start:
1. flutter pub get
2. flutter run -d web-server
